ldx 런타임 워크플로 v2 — 등록부터 결과까지

빨간 테두리 = 원본 불변 장치. 읽기 실패(인코딩·손상·잠김)는 멈추지 않고 limitations[]에 남기고, SQL 가드 거부·원본 불변 위반·카탈로그 잠김은 오류로 즉시 중단한다.

A. 적재 경로 — ldx source add <폴더> → ldx scan

1소스 등록
  • 폴더 경로 기록
  • 그 안의 .ldx는 스캔 제외
→
2스캔
  • 정션·심볼릭 링크 안 따라감
  • 숨김·~$*.xlsx 제외
  • size · mtime_ns
  • 한도 초과 → 경고
→
3변경 감지
  • size·mtime_ns가 다른 것만 sha256(공유 모드로 열기)
  • 신규·변경·삭제만
  • 열 수 없으면 locked
→
4파싱 (어댑터)
  • SQLite: WAL → 스냅샷 복사 / 비WAL → as_uri+mode=ro+query_only
  • CSV: 인코딩 지정·재시도, 행 단위 거부 기록, empty
  • Excel: bytes로 읽기, 시트별 테이블
  • 파싱 전후 해시가 다르면 재시도
원본 불변 ① 읽기 전용 또는 복사본만 연다
→
5프로파일
  • 처음 1,000행 기본
  • 표본·근사 표시
  • unique 정확 계산
→
6카탈로그 기록
  • 짧은 쓰기 연결
  • 잠기면 catalog_busy
→
7색인
  • Kiwi 형태소 → BM25
  • 문자 n-gram (코드·숫자)
  • 범위: 이름·상위값·표본 (셀 전체는 시나리오 후 결정)

B. 검색 경로 — ldx search "창업 지원"

8질의 전처리
  • 원문 보존
  • 형태소·n-gram·자모
→
9Retriever
  • BM25 · n-gram
  • Fuzzy(cutoff)
→
10RRF
  • 점수 출처 유지
  • 결과 없음 허용
→
11결과
  • 파일·시트·열·행 — 값

C. 조회 경로 — ldx query --sql "…"

12읽기 전용 SQL 가드
  • 문장 수 = 1
  • json_serialize_sql
  • CTE 안 DELETE 등 거부
원본 불변 ②
→
13엔진 설정 (engine.py, 순서 고정)
  • adapters가 만든 ATTACH 명세 실행(READ_ONLY)
  • temp_directory 절대경로
  • external access 끄기 · autoinstall 끄기
  • lock_configuration
원본 불변 ③ 등록 안 된 파일·확장 설치 차단
→
14실행
  • in-memory 연결
  • 시간·행 제한
→
15결과
  • 잘림 표시

D. 공통 출구

결과 봉투 (types.py)
  • { ok, data, truncated, total_rows, total_rows_exact, limitations[], read_completeness }
  • CLI는 stdout에 하나, 실패는 stderr + 종료 코드 / 화면은 같은 봉투를 렌더링
→
✓명령 전후 검사 (런타임)
  • 원본 폴더 목록·부속 파일(-wal/-shm/-journal/.tmp) 비교
  • 위반 시 immutability_violation 오류
원본 불변 ④ (해시 불변은 사본 테스트에서)
