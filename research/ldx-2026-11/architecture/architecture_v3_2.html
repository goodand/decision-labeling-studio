ldx 아키텍처 v3.2 — 판정표 v3.1(Y1~Y18)·실측 F1~F4 반영

파랑 = 재사용 코드, 노랑 = 접착 코드, 주황 굵은 테두리(✎쓰기) = .ldx에 쓰는 모듈, 회색 점선 = 확장 자리. 원본(빨간 점선)은 stat·파일 복사·바이트 읽기만(한 번 읽고 즉시 닫음). 모든 DB 연결은 .ldx 안 사본에 mode=ro&immutable=1.

① 사용자 접점
사람: Datasette 웹 ([web] 선택 설치)
  • 표 보기·필터·SQL(1초 상한)·FTS, datasette-search-all
  • 명령 계층 밖: 봉투·Kiwi·짧은 단어 처리·positions-only 미적용 → 배너에 고정 문구로 알림. SC7 DB는 올리지 않음
serve.py
  • catalog가 준 현재 사본 경로 목록으로 Datasette 프로세스 실행
  • catalog 세대 번호를 폴링 → 바뀌면 재기동(약 1.2초), 실패 시 이전 목록으로 재기동
  • 재기동 뒤 catalog.gc_generations()
  • 배너 플러그인: 서버가 실제 연 사본의 snapshot_at, staleness, limitation
cli.py (typer, 인자 처리만)
  • source add · scan · show · search · compare · query --source · export · serve
  • compare 도움말: "나란히 보여 줌, 합치지 않음"
  • stdout JSON 1개 / stderr 오류 + 종료 코드
확장 자리
  • MCP 서버, 웹 대조 화면
  • 상주 Kiwi 정규화
  • 출력 render(envelope, fmt)
↓ cli.py만 app.py를 부른다 · serve·배너는 catalog를 읽기 전용(WAL)으로 직접 조회
② app.py — 명령 함수(결과 봉투를 돌려줌, 단일 진실의 범위 = ldx 명령)
scan · show · search · compare · query · export 함수
  • 봉투 {ok, data, truncated, total_rows, total_rows_exact, limitations[], read_ratio, read_scope{files, tables}, snapshot_at}
↓
③ 기능 모듈 (최소 구성)
scan.py
  • 잠금 파일로 scan끼리 배타
  • 허용 확장자만 순회(xlsx·xls·csv·sqlite·db), 부속 파일은 본체에 묶음, ~$이름 있으면 "열려 있음"
  • 변경 시그니처: 본체+-wal·-journal(존재·크기·mtime), 같을 때만 앞뒤 64KB 해시
  • 변경 판별 뒤 디스크 점검(×4 + 남은 세대)
  • snapshot → convert → catalog 기록 → gc
snapshot.py
  • 부속 파일을 <ID>.db-wal·-journal로 이름 맞춰 복사
  • 본체+부속 전후 stat 같을 때 채택(재시도)
  • 사본을 읽기·쓰기로 열어 롤백·체크포인트 → journal=delete → quick_check(손상 감지 보조)
convert.py
  • python-calamine(엑셀, 메모리 바이트) / csv(utf-8-sig→cp949)
  • sqlite-utils: 시트별 표 + _source_row, 첫 행=머리행, 중복 열 _2, 빈 시트 0행+limitation
  • 원문 FTS5 trigram(enable_fts)
  • SC7 시트 → 별도 DB
textindex.py
  • kiwipiepy 묶음 호출(357만 자/초)
  • 형태소 사이드 표 <표>__kw(unicode61 FTS5, rowid 연결), 사용자 표 불변
  • 질의 정규화도 여기(같은 설정), 세대 메타에 kiwi 버전·옵션
  • 질의에 한글 있을 때만 로드
search.py (+ compare 함수)
  • 단어별: 형태소마다 [사이드 표 MATCH] OR [3글자↑ 원문 trigram / 미만 LIKE], 단어끼리 AND (quote_fts 재사용)
  • FTS 없는 표·WITHOUT ROWID → 제외+limitation
  • compare: 정확 일치 먼저, 부분 일치 표시, 소스별 잘림 전달
query.py
  • 표준 sqlite3: set_authorizer(SELECT·READ·FUNCTION·RECURSIVE + 읽기 PRAGMA 이름 목록), 한 문장, query_only, 확장 로드 끔
  • set_progress_handler → query_timeout
  • --source로 사본 하나 지정, SC7 표는 원문 제거
export.py
  • .ldx/exports/만, realpath·normcase
  • .ldx/tmp에 쓰고 os.rename(교체 금지), 있으면 거부
  • csv(utf-8-sig, 엑셀로 열림)·sqlite
catalog.py (WAL)
  • 경로·스키마·파일 단위 세대의 유일 소유자
  • 소스별 현재 사본 포인터, 새 세대는 마지막 짧은 트랜잭션
  • staleness(path), gc_generations()(참조 0만, 실패 재시도)
확장 자리
  • reader(path) -> sheets
  • searcher(query, tables) -> hits(n-gram·fuzzy)
  • 증분 변환, 자동 감시
↓ 모든 모듈 → types.py(의존 없음: 봉투·오류 종류 sql_rejected · query_timeout · catalog_busy · source_locked · not_registered · disk_low · source_overlap)
